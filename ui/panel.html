ZCode 规则

插件版本 v0.2.0 · 面板形态：静态占位（session 级）

当前状态

本页为静态占位页，不含任何交互控件。当前规则与内容策略状态由 MCP 工具返回，面板不缓存、不猜测：

  • rules_read / rules_write — 结构化规则（rules.json）
  • content_policy_read / content_policy_write — 自由文本内容策略（content-policy.json）
  • export_agents — 把两段投影到 AGENTS.md（双哨兵）
  • selfcheck_run — 规则 / 策略 / 投影 / 尺寸 / 版本自检

空规则 + 空策略 = 零行为变化：不写规则时，本插件不改变 ZCode 的任何默认判定。

数据目录

数据目录由宿主在启动 MCP server 时通过 ZCODE_RULES_DATA（等价 ZCODE_PLUGIN_DATA）注入；本页不读写磁盘，也不猜测路径。

AGENTS.md 默认指向用户级 ~/.zcode/AGENTS.md；导出与自检都支持显式路径覆盖。
